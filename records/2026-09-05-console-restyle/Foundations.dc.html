Scope note. The reference material examined for this spec (a separate project's Claude Design pass, light and editorial) points in a direction opposite the console's deliberately dark, dense, monospaced identity — the two were flagged as incompatible during planning, and the aesthetic direction was left open pending the user. Absent that decision, this canvas stays structurally faithful: it organizes the existing palette into a named system without changing a single value, so the restyle in Task 16 is provably a rename and every presentation clause from phases 3–6 stays green untouched. A values-level visual refresh is a follow-up the user can scope separately, now that the token seams exist to carry it.
