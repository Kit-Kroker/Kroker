Companion to Implementation Roadmap · Sources: ARCHITECTURE.md, ROADMAP.md

A deterministic state machine over a fixed 15-stage DAG, executed as a Temporal workflow. Proposer agents emit schema-validated artifacts; coding harnesses act only inside risk-classed git worktrees; humans hold configurable decision gates; a shared memory makes the system learn across runs. This page overlays what is built today on the architecture's canonical shape.

Failure modes §11

  • done Worker crash mid-harness-run → heartbeat timeout, retry from checkpoint.
  • done LLM/API outage → activity retry + backoff.
  • partial Human absent at gate → timeout→auto-reject only (no reminder/fallback).
  • done Fix loops exhausted → escalation gate (accept / retry-with-guidance / quarantine).
  • done Quarantined task → dependents blocked, clean failure.
  • partial Payload > limits → sessions claim-checked (ArtifactStore, E-38); diffs still inline, no runtime guard (FR-702).
  • done Hindsight down → empty snapshot (logged).
  • done Prompt edited mid-fleet → memoization hash invalidates affected stages only.

Toolchain adapters for language-agnostic evaluationADR-15

Stage-11/12 quality activities cannot hardcode one toolchain. A ToolchainAdapter registry (TOOLCHAINS, beside HARNESSES) resolves by marker file in the produced repo (pyproject.toml/package.json/go.mod/Cargo.toml); canonical coverage = Cobertura XML, absolute security floor = semgrep → SARIF, so the deterministic gate stays language-agnostic and unchanged. Landed (E-30): registry + marker detection + Python reference end-to-end; run_integration_checks closes the FR-106 coverage-crossing gap. Go/TS/Rust = E-30a/b/c.

Harness sessions as first-class, claim-checked artifactsADR-16

Every harness run emits a canonical HarnessSession as session_ref: ArtifactRef{kind: harness_session} on HarnessRunResult. Always-on ⇒ claim-check unconditional, scrub fail-closed before storage, retention decided (full on fail/benchmark/attempts>0, SessionDigest on clean-green). Landed (E-38): per-adapter normalisers (claude stream-json, opencode event stream) + ArtifactStore (file:// backend) + fail-closed capture in run_coding_task + retro-time OQ-B7 retention. The P5 trajectory seam; deep_review reads it as data (E-39). Full-transcript TTL still open (OQ-B7).

Containment as a declared harness capabilityADR-17

A CodingHarness declares which layers it enforces (native/hook); one versioned policy/containment.yaml compiles per adapter. Native is the inner layer, hook the outer; total absence of layers fails closed (cursor), partial coverage recorded in ContainmentReport. Landed (E-15/E-16): fail-closed PreToolUse hook (python -m sdlc.harness.hook) + four predicates + ToolDenial on HarnessRunResult/SessionDigest. A fence, not a sandbox — denial is tool-level only; OS/container/network tier is E-21.
