## Уроки

1. `temporal server start-dev` **без `--db-path`** + WSL-рестарт = потеря всех прогонов.
   Долгие прогоны требуют персистентности (+ `restart: always` для temporal в compose —
   сейчас политики нет).
2. Reset — хирургия по **явному event-id**; точка обязана быть **до** activity, чей
   результат пересчитываем (после — возьмётся кэш из истории). `LastWorkflowTask`
   врёт на длинных рана́х.
3. Песочница без docker: контракты, требующие сервисов (Qdrant/Postgres), будут
   эскалировать всегда. Либо сайдкар-сервисы в сети воркера, либо оператор с рецептом
   верификации до approve.
4. Внешнее состояние (борд, git, uv в слое контейнера) не отматывается вместе с
   историей — каждый replay-сценарий натягивает инварианты; гварды должны следовать
   истории.
5. Операторская обвязка спасала: экспорт спек из истории Temporal (артефакты до
   публикации на борд), markdown-рендеры, seeded-путь как план восстановления.
6. **Merge-гейт проверяет корректность диффа, не развёртываемость.** 9 из 10 дефектов
   дня 2 — «SQLite-тесты против прод-Postgres» и отсутствующий прод-wiring; ни один
   не мог быть пойнан юнитами. Подъём стека — отдельная фаза качества. Дефект №10 —
   класса «подсистема собрана и протестирована, но не подключена»: юниты зелёные,

7. Дефолты LLM-обвязки (таймаут 30 с, max_tokens 2048) рассчитаны на быстрые
   EU-эндпоинты; за прокси с большими рубриками оба режут легитимные ответы.
