# Contract: the read-only route tail (FR-060 to FR-063)

There are four GET routes under `/api`, registered by `D/read_routes.py` (data-model §2.5). Shapes are in data-model §2.

## Rules common to all four

1. **Read-only.** No store write, no Temporal signal or update, no file write. `GraphStore.put` is never called. Shas are computed in memory with `content_sha()`. `apply_containment` is never called.
2. **Stateless.** Every response is computed per request. The only exceptions are the existing `RunGraphs` cache and the existing fleet poller. Neither gains new state.
3. **Never a 500 for missing data.** A source that is missing, unreadable or mid-write yields `not measured` (`None` on the wire) in the affected field, or `available: false` with the root path that was read. A 500 is reserved for a programming error.
4. **Mirrors.** Each wire model gets a recorded fixture in `F/api/__fixtures__/read/<route>.json`. The fixture is generated by `scripts/dump_read_fixtures.py` from the fixture inputs, never from live data, and is pinned by `tests/test_read_fixtures_fresh.py`. Pinning works the same way as `tests/test_graph_fixtures_fresh.py`.
5. **Deny-list guard.** `tests/test_018_diff_guard.py` fails if the branch diff against its merge base touches `src/sdlc/{benchmarks,stages,workflows,harness,core}/` or a foreign-diff path (FR-061, SC-007). It runs only when `KROKER_DIFF_GUARD=1`, which the slice gates set, so it never runs inside a benchmark worker.

## `GET /api/fleet/summary` (R-6)

- **Input:** none.
- **Output:** one `FleetRunSummaryWire` per run in `poller.snapshot()` (open and closed). Runs whose source read fails are listed in `unreadable`.
- **Derivations:**
  - `graph_sha` and `graph_name`: from `RunGraphs.source(run_id).run_input.graph.content_sha()`, matched against `{g.content_sha(): name for name, g in SHIPPED.items()}`.
  - `arm`: the `dev` entry of `resolved_roles(run_input.cfg)`, giving harness and model.
  - `traversals`: the back edges with the state's counts and the edge's `max_traversals`.
  - `outcome` and `where`: from the existing graph-state projection.
  - `gate_timeouts`: `run_input.cfg.gates`.
- **Legacy run** (no run input): `graph_sha: null`, `arm: null`, `traversals: []`, `outcome: null`.
- **Tests:** shipped-name match, custom sha, legacy run, unreadable run, and back-edge counts. Each test reuses the fakes in `tests/test_dashboard_run_graph_routes.py`, read before writing.

## `GET /api/graphs/shipped` (R-7)

- **Output:** three graphs, plus checks and sections.
- **Tests:**
  - counts equal the YAML;
  - `seeded` has no gates;
  - `check_adr6_families` pass and fail through a monkeypatched role map;
  - the same-weights note when `model_id` values are equal;
  - every limits row present, or `None` when the field is absent from `PipelineConfig`.

## `GET /api/interfaces` (R-8)

- **Output:** columns in key order: `layers`, `strict`, `family`, `installed`, `checkpoint`, `session`.
- **Row states:**
  - `installed`, `checkpoint` and `session` are `not_measured` on every row;
  - `pyai` is all `planned`;
  - `family` is filled only on the row whose harness equals the registry `dev` harness, and is `not_measured` elsewhere.
- **Parity test:** for claude_code and opencode on the shipped policy, the derived `strict` matches what each adapter's `rules_unenforceable` computes. The test calls the adapter path inside a temp dir. This test is the only place `apply_containment` runs, and it never runs in the route.
- **Import test:** importing the route module performs no filesystem write.

## `GET /api/compare` (R-9)

- **Input:** none. The root is `$SDLC_RUNS_ROOT`, or else `./runs`.
- **Output:**
  - `available: false` when the root has no benchmark records; `root` always names the path read;
  - otherwise arms × graphs, with SC and $/case `None` where absent;
  - `heat_columns`: the `CELL_STAGE_ORDER` members present in the layer;
  - cells `low_n` where the layer says so.
- **Tests:**
  - an empty root;
  - a fixture tree with two arms × two graphs;
  - a truncated JSONL line, which is skipped and does not cause a 500;
  - an unpriced arm, giving `cost_per_case: None`.
